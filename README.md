📄 Research Paper Intelligence System | RAG + LLM + GenAI:

Built a Research Paper Intelligence System that allows users to upload multiple research papers, search across them, and get AI-generated answers with source and page references.

🔧 Tech Stack:
Python • PyMuPDF • Sentence Transformers • FAISS • Gemini API • RAG • Flask • REST API • React.js

⚙️ Backend:
PDF text extraction and page-level metadata using PyMuPDF
Text chunking and 384-dimensional embeddings using all-MiniLM-L6-v2
Semantic search using FAISS Vector Database
RAG pipeline for retrieving relevant research content
Gemini LLM for contextual answer generation
Flask-based backend and API integration

🎨 Frontend:
Built a React.js interface
PDF upload functionality
Research paper search/Q&A interface
Displays AI responses with source papers and page numbers

✨ Features: Multi-paper Q&A • Paper Summarization • Methodology/Dataset/Results Extraction • Paper Comparison • Research Gap Generation
